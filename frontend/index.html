Assessment Breakdown
30%
Continuous Assessment (CA)
Mid-semester tests, weekly quizzes, and laboratory practicals. Usually 1–2 tests across the semester. Crucial for Network Security and coding courses.
70%
Final Examination
Comprehensive theoretical or practical exam held at the end of the semester. This is the largest component — the AI tells you exactly what score you need here.
💡 Example: If your target is A (70%) and you score 65% in CA, you contributed 65 × 0.30 = 19.5 marks. You still need 50.5 out of 70 from your exam — which is 72.1%. The AI calculates all of this for you instantly.

Getting Started
Run in 3 Steps
Pure Python — no framework needed. If Python is installed, you're ready to go.
1
Install Python
Download from python.org. Tick "Add Python to PATH" during installation — this is required on Windows.
pip install scikit-learn numpy
2
Start the Server
Windows: Double-click START_SERVER.bat

Mac/Linux: Run in terminal:
cd backend
python server.py
3
Open & Register
Open index.html in Chrome or Firefox. Click a portal, create your account, and start planning your semester.
⚠️ Windows Users: Do not type python3 — use python instead, or just double-click START_SERVER.bat and it handles everything automatically.
